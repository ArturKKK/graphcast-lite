# wb2_64x32_15f_4pred — multi-step output без AR-цикла

Та же 15-канальная модель на 64×32, но decoder выдаёт сразу **4 шага вперёд** (+6/+12/+18/+24 ч) одним forward-pass'ом. Это альтернатива авторегрессии: модель «угадывает» весь интервал за один проход, AR-цикл с feedback'ом не используется.

> Состав 15 переменных — тот же, что и в `wb2_64x32_15f`. См. `variables.json` датасета.

## Что было

| Параметр | Значение |
|---|---|
| Датасет | `wb2_64x32_zq_15f_4obs_4pred` |
| Разрешение сетки | 64 × 32 |
| Число переменных | 15 |
| `obs_window_used` | 4 шага (24 ч истории) |
| `pred_window_used` | **4** шага (24 ч цели) |

## Как обучалось

| Параметр | Значение |
|---|---|
| `batch_size` | 1 |
| `learning_rate` | 1e-3 |
| `num_epochs` | 50 |
| `use_latitude_weighting` | не задано |
| `max_ar_steps` | не задано (модель выдаёт 4 шага одним проходом) |

## Архитектура

- **Граф**: `mesh_levels=[4, 6]`
- **Encoder**: MLP `[64,64]→64` + GCN `[96,96]→96`
- **Processor**: GCN `[96,96,96]→96`
- **Decoder**: MLP `[64,64]→64` + GCN `[48,48]→**60**` (= 15 переменных × 4 шага)

## Что нового по сравнению с `wb2_64x32_15f`

| | 15f | 15f_4pred |
|---|---|---|
| `pred_window_used` | 1 | **4** |
| `decoder.output_dim` | 15 | **60** (4×15) |
| Тип многошагового прогноза | — | **Direct multi-output** (один forward) |

Это чисто архитектурное изменение в decoder — никаких новых трюков обучения. Идея: получить +24 ч прогноз без compound errors AR-цикла.

## Ограничения подхода

- Direct multi-output не учит модель «переваривать» собственные ошибки → нет защиты от drift'а при попытке rollout дольше 4 шагов.
- Decoder с 60 выходами тяжелее регуляризуется.
- Latitude-weighting и static/forcing-каналы всё ещё отсутствуют.

В следующей версии (`wb2_64x32_ar_15f_4obs_4pred`) этот подход заменили на настоящую авторегрессию.
