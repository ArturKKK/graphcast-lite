# wb2_512x256_19f_ar — первая полноразмерная (0.7°) глобальная версия

Скачок разрешения: с 64×32 (≈5.6°) на **512×256 (≈0.7°)** — это «настоящий» WeatherBench2 grid. Каналов 19 (полный базовый набор). Модель снова авторегрессивная (AR=4), широтные веса включены.

## Что было

| Параметр | Значение |
|---|---|
| Датасет | `wb2_512x256_19f_ar` |
| Разрешение сетки | **512 × 256 (≈ 0.7°)** |
| Число переменных | **19** |
| `obs_window_used` | 2 шага (12 ч истории) |
| `pred_window_used` | 1 шаг (за 1 forward, AR разворачивает loop) |

### 19 базовых переменных WeatherBench2 (стандартный состав репозитория)

| idx | имя | смысл |
|---|---|---|
| 0 | `t2m` | температура на 2 м |
| 1 | `10u` | зональный ветер 10 м |
| 2 | `10v` | меридиональный ветер 10 м |
| 3 | `msl` | давление, приведённое к уровню моря |
| 4 | `tp` | суммарные осадки |
| 5 | `sp` | поверхностное давление |
| 6 | `tcwv` | total column water vapour |
| 7 | `z_surf` | геопотенциал поверхности (рельеф, статика) |
| 8 | `lsm` | land-sea mask (статика) |
| 9–13 | `t/u/v/z/q @ 850 hPa` | температура, ветры, геопотенциал, влажность на 850 гПа |
| 14–18 | `t/u/v/z/q @ 500 hPa` | то же самое на 500 гПа |

## Архитектура

- **Граф**: `mesh_levels=[4, 6]`, grid→mesh — radius (0.6), mesh→grid — contained
- **Encoder**: MLP `[128,128]→128` + GCN `[128,128]→128`
- **Processor**: GCN `[128,128,128,128]→128` (4 слоя `conv_gcn`, layer-norm)
- **Decoder**: MLP `[128,64]→64` + GCN `[64,64]→**19**`
- Скрытая размерность — **128** (vs 96 в 64×32-моделях).

## Что нового по сравнению с `wb2_64x32_ar_15f_4obs_4pred`

| | 64x32_ar_15f | **512x256_19f_ar** |
|---|---|---|
| Сетка | 64×32 (~5.6°) | **512×256 (~0.7°)** |
| Каналов | 15 | **19** (+4: tp, sp, tcwv, z_surf, lsm — точнее: добавлены `tp/sp/tcwv` и статические `z_surf/lsm`) |
| Окно входа | 4 шага (24 ч) | 2 шага (12 ч) |
| Hidden dim | 96 | **128** |
| Processor слоёв | 3 | **4** |
| Learning rate | 1e-3 | 5e-4 (нужнее меньший шаг на большом графе) |
| AR | 4 | 4 (то же) |
| Weighted Loss | ✅ | ✅ |
| Early stopping | ❌ | **✅** (patience=12) |

## Что всё ещё отсутствует

- Processor — только `conv_gcn`, без InteractionNetwork и edge-features.
- Активация — PReLU/ReLU по умолчанию, не Swish.
- Нет `static_channels` / `forcing_channels` — статические `z_surf`/`lsm` учатся как обычные каналы (модель тратит ёмкость на «предсказание» вещей, которые не меняются).
- Нет input-noise injection и per-channel weights.

Эти улучшения добавились в `wb2_512x256_19f_ar_v2` (новая архитектура processor).
