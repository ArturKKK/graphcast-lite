# wb2_64x32_11f — baseline на грубой сетке

Самая первая «глобальная» конфигурация: WeatherBench2 на сетке **64×32**, 11 переменных. Это отправная точка проекта — простая модель, без авторегрессии, без широтных весов, на низком разрешении.

> Точный список 11 переменных задаётся при создании датасета `wb2_64x32_11f_2obs_1pred` (см. `variables.json` в его папке `data/datasets/`).

## Что было

| Параметр | Значение |
|---|---|
| Датасет | `wb2_64x32_11f_2obs_1pred` |
| Разрешение сетки | 64 × 32 (≈ 5.6° × 5.6°) |
| Число переменных (`num_features_used`) | 11 |
| Окно входа (`obs_window_used`) | 2 шага по 6 ч (= 12 ч истории) |
| Окно цели (`pred_window_used`) | 1 шаг (= +6 ч) |

## Как обучалось

| Параметр | Значение |
|---|---|
| `batch_size` | 1 |
| `learning_rate` | 1e-3 |
| `num_epochs` | 70 |
| `random_seed` | 42 |
| `use_latitude_weighting` | **не задано** (= по умолчанию, без широтных весов) |
| `max_ar_steps` | **не задано** (= 1, без авторегрессии) |
| wandb | выключен |

## Архитектура

- **Граф**: `mesh_levels=[3, 5]`, grid→mesh — radius (0.5), mesh→grid — contained
- **Encoder**: MLP `[48,48]→64` + GCN `[64,64]→64` (`conv_gcn`, layer-norm на node-уровне)
- **Processor**: GCN `[64,64,64]→64` (`conv_gcn`, layer-norm)
- **Decoder**: MLP `[64,64]→64` + GCN `[48,48]→11`
- Скрытая размерность — 64.

Это конфигурация уровня «учебного примера»: маленький меш (≈10k узлов), узкие MLP, без residual-механизма.

## Что отсутствует

- Нет авторегрессии — модель учится только на +6 ч.
- Нет весов по широте — экватор и полюса в loss равноправны.
- Нет статических каналов / forcing — все 11 каналов учатся одинаково.
- Низкое разрешение (5.6°) — нет ни синоптических деталей, ни ROI.

## Журнал

Используется как baseline для сравнения дальнейших версий.
