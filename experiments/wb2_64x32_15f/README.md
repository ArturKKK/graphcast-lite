# wb2_64x32_15f — +4 переменные, более длинная история, более глубокий граф

Второе поколение «64×32» конфигурации: +4 переменные (отсюда суффикс `_zq` в датасете — добавлены каналы геопотенциала z и влажности q), окно входа удлинено с 2 до 4 шагов, увеличен меш и скрытая размерность.

> Точный список 15 переменных задаётся датасетом `wb2_64x32_zq_15f_4obs_1pred` (см. `variables.json` в `data/datasets/`).

## Что было

| Параметр | Значение |
|---|---|
| Датасет | `wb2_64x32_zq_15f_4obs_1pred` |
| Разрешение сетки | 64 × 32 |
| Число переменных | **15** (vs 11 в v1) |
| `obs_window_used` | **4** шага = 24 ч истории (vs 2 = 12 ч) |
| `pred_window_used` | 1 шаг (+6 ч) |

## Как обучалось

| Параметр | Значение |
|---|---|
| `batch_size` | 1 |
| `learning_rate` | 1e-3 |
| `num_epochs` | 50 |
| `use_latitude_weighting` | не задано |
| `max_ar_steps` | не задано (= 1) |

## Архитектура

- **Граф**: `mesh_levels=[4, 6]` (vs [3,5]) — **более плотный икосаэдрический меш**
- **Encoder**: MLP `[64,64]→64` + GCN `[96,96]→96`
- **Processor**: GCN `[96,96,96]→96`
- **Decoder**: MLP `[64,64]→64` + GCN `[48,48]→15`
- Скрытая размерность — **96** (vs 64).

## Что нового по сравнению с `wb2_64x32_11f`

| | 11f | 15f |
|---|---|---|
| Каналов | 11 | **15** (+4) |
| Окно входа | 12 ч (2 шага) | **24 ч (4 шага)** |
| Меш | [3, 5] | **[4, 6]** (плотнее) |
| Hidden dim | 64 | **96** |
| Эпох | 70 | 50 |

Идея: больше информации на вход + более выразительный граф → лучше синоптика на той же сетке.

## Что всё ещё отсутствует

- Нет авторегрессии (только +6 ч).
- Нет latitude-weighting.
- Нет static_channels / forcing.
