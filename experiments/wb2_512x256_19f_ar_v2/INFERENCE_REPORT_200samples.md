# v2 GLOBAL — инференс 200 сэмплов (14 мая 2026)

**Модель:** wb2_512x256_19f_ar_v2 (19 каналов, base set)
**Состояние:** завершённое обучение, best_model.pth (27 MB)
**Тест:** 200 сэмплов из 1753, AR=4 (+6/+12/+18/+24 ч), grid 512×256
**Команда:** `python scripts/predict.py experiments/wb2_512x256_19f_ar_v2 --max-samples 200 --ar-steps 4 --per-channel --no-save --no-residual --data-dir /data/datasets/wb2_512x256_19f_ar --ckpt .../best_model.pth`

**Gotcha:** v2 обучалась с `use_residual=false`, а `predict.py` по умолчанию суммирует `X_last + delta`. Первый прогон без `--no-residual` дал бред (RMSE 3.9, t2m ~85°C). После добавления флага — нормальные метрики.
