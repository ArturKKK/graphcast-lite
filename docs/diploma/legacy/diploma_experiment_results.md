### 1.4 wb2_512x256_19f_ar_v2 — Улучшенная глобальная модель

**Ключевые изменения v1 → v2:**

| Параметр | v1 | v2 |
|---|---|---|
| Processor | conv_gcn (4 слоя) | **InteractionNetwork** (12 MP steps) |
| Edge features | Нет | **4D** (distance + 3D relative pos) |
| Residual connections | Нет | **Да** (node + edge) |
| Latent dim | 128 | **256** |
| Activation | PReLU | **Swish (SiLU)** |
| LR | 5e-4 | **3e-4** |
| Epochs | 60 | **80** |
| Параметры | ~210K | **~5.9M** (28×) |

**Конфиг (полный):**
- **Encoder MLP:** [256,256]→256, LayerNorm; GCN: conv_gcn [256,256]→256, swish
- **Processor:** interaction_net, output_dim=256, 12 MP steps, edge_feature_dim=4, swish, LayerNorm
- **Decoder MLP:** [256,128]→128; GCN: conv_gcn [128,128]→19, swish
- **Training:** lr=3e-4, 80 epochs, patience=15, latitude_weighting=true, max_ar=4
