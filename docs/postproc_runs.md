# Учёт прогонов постобработки

Заполняется автоматически из `scripts/postproc/record_run.py`, который зовут
раннеры после каждой проверки. Руками сюда писать не нужно.

Проверка везде — 2020 год, 485 888 строк (те, где есть все три наблюдения).
Сырой прогноз на ней: t2m 2,978 °C, ветер по вектору 2,353 м/с.

**Как сравнивать.** Сначала смотрите на графу «призн.»: состав признаков рос по
ходу дня, и две строки с разным числом признаков отличаются не только тем, что
написано в примечании. Например, `_s43` считался уже с разностью высот, поэтому
мерить по нему разброс от жребия надо против `_dz`, а не против основной
настройки: у обеих по 62 признака.
