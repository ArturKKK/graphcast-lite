## 7. MOS/IDW Постпроцессинг (sweep)

Оценка на 50 тестовых сэмплах, +6h, региональные узлы (2501).

| Конфигурация | t2m RMSE (°C) | Skill vs Persistence |
|-------------|---------------|---------------------|
| Persistence (last obs) | 7.236 | — |
| **GNN raw** | **2.083** | **71.21%** |
| GNN + lapse | 2.868 | 60.36% |
| GNN + lapse + MOS (station only) | 2.938 | 59.39% |
| GNN + lapse + MOS + IDW (p=2.0, r=50km) | 3.582 | 50.50% |
| GNN + lapse + MOS + IDW (p=2.0, r=100km) | 4.305 | 40.51% |
| GNN + lapse + MOS + IDW (p=2.0, r=150km) | 4.942 | 31.70% |
| GNN + lapse + MOS + IDW (p=2.0, r=200km) | 5.517 | 23.75% |
| GNN + lapse + MOS + IDW (p=2.0, r=300km) | 6.487 | 10.35% |
| GNN + lapse + MOS + IDW (p=3.0, r=100km) | 4.305 | 40.50% |
| GNN + lapse + MOS + IDW (p=3.0, r=150km) | 4.943 | 31.68% |
| GNN + lapse + MOS + IDW (p=3.0, r=300km) | 6.492 | 10.28% |
| GNN + lapse + MOS + IDW (p=1.5, r=150km) | 4.942 | 31.71% |
| GNN + lapse + MOS + IDW (p=1.5, r=300km) | 6.485 | 10.38% |

### Ключевые выводы по MOS:

1. **GNN raw даёт лучший результат** (2.08°C) — постпроцессинг ухудшает.
2. **Lapse-коррекция вредит** (+0.79°C деградации) — модель уже учитывает рельеф через z_surf.
3. **MOS station-only** даёт минимальное изменение поверх lapse.
4. **IDW spatial interpolation катастрофически ухудшает** — распространяет станционные bias на всю сетку.
5. **Параметр power (1.5, 2.0, 3.0) не влияет** — проблема в самом IDW-подходе.
6. **Меньший радиус лучше** (r=50 > r=100 > ... > r=300), подтверждая, что IDW вредит.

**Рекомендация:** Для merge-датасета постпроцессинг не нужен. GNN raw — оптимален. MOS/IDW полезен только для live pipeline с единичными станциями.
