# Логи расчётов для статьи

Каждый `.log` начинается с блока `### PROVENANCE ###`, где записаны:
команда запуска, git-коммит, GPU, метаданные датасета, md5 конфига и весов.
Поэтому любой результат прослеживаем без обращения к этой странице.

`MANIFEST.md` в каждом наборе — сводка: коммит/ветка, версии torch и драйвера,
все датасеты с метаданными, md5 всех чекпойнтов, таблица логов с командами.

`*_samples.npz` — per-sample MSE (по срокам × горизонтам × каналам, глобально и по ROI)
для расчёта доверительных интервалов блочным бутстрепом.

## Наборы

| каталог | что внутри | окно верификации |
|---|---|---|
| `vm3_m2m3/` | M2 (флагман, freeze6, nofreeze — ROI и внутренняя зона) + M3 (контроль равных эпох) | полный test_only, 1607 сроков, все сезоны |
| `vm3_m1/` | M1 — усвоение на длинных горизонтах, AR-28 (+168 ч) | 200 сроков, AR-28 |

## Сводка результатов

**M2 (ROI 2501 узел), t2m RMSE °C на +6/+12/+18/+24 ч:**

| модель | +6 | +12 | +18 | +24 | Skill региона |
|---|---|---|---|---|---|
| флагман `multires_merge_freeze6_v2` | 1.39 | 1.66 | 1.74 | 1.84 | 69.44% |
| `nores_freeze6` | 1.34 | 1.59 | 1.71 | 1.82 | 60.75% |
| `nores_nofreeze` | 1.36 | 1.65 | 1.81 | 1.96 | 59.85% |

**M3 (контроль равного бюджета, эпоха 16 у обеих моделей):**
freeze6 → 1.82 °C; nofreeze → 1.82 °C. Разница по температуре исчезает.
Вывод: выигрыш заморозки в M2 объясняется выбором чекпойнта (у nofreeze лучший
по val_loss — эпоха 7, хуже в авторегрессии), а не самой заморозкой.

**M1 (AR-28, 200 сроков), t2m RMSE °C / Skill региона:**

| горизонт | без усвоения | ОИ 10% |
|---|---|---|
| +24 ч | 2.11 / 73.3% | 1.12 / 85.3% |
| +48 ч | 2.59 / 69.1% | 1.31 / 86.2% |
| +96 ч | 4.07 / 51.4% | 1.57 / 84.9% |
| +120 ч | 5.06 / 39.6% | 1.72 / 83.2% |
| +168 ч | 7.31 / 18.9% | 2.23 / 78.3% |

⚠️ Усвоение — эксперимент «идентичных близнецов»: наблюдения берутся из самого
реанализа в 10% узлов ROI, без приборной погрешности. Это верхняя граница эффекта.
